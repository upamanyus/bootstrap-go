# bootstrap-go (Lean)

This branch (`lean`) holds two Go checkers for Goose code and the **Lean**
port of their Rocq side. It has its own history; the Rocq development is on
branch `main`. Perennial's Lean port (branch `lean` of
[mit-pdos/perennial](https://github.com/mit-pdos/perennial)) is a Lake
dependency, pinned in `lake-manifest.json`, not a copy: the framework,
Goose, and Perennial's own proofs live there.

- `checker/` — a CSL symbolic-execution checker, **proved sound** in Lean
  (`Checkers/Checker/`, `check_sound`, `check_adequate`).
- `tcheck/` — a table-driven checker whose rules are proved lemmas; its
  soundness is the one stated axiom `check_adequate`
  (`Checkers/TCheck/Observe.lean`). Its client is etcd raft's
  `becomeFollower`, over the Lean raft election proof (the `etcdGrove`
  dependency).

## Read the notes first

`notes/` is this project's persistent memory: plain markdown, committed.

- Start at `notes/STATUS.md`; `notes/README.md` lists the rest.
- **Before you finish, update the notes**: `notes/STATUS.md` if anything
  moved, plus a dated entry appended to `notes/journal.md`.

## Layout

- `checker/`, `tcheck/` — the checkers' cores (Go, translated by Goose: no
  imports). `gocheck/` — their frontends (not translated, not trusted).
- `Generated/` — Goose's Lean output for this repository's packages.
  **Generated by `etc/goose.sh`; do not edit.**
- `Checkers/` — the Lean development. `notes/porting.md` maps every Rocq file
  on `main` to its Lean file. `Checkers/Native/` (not a port) proves the
  Lean-native checker sound (`lcheck_sound`) and runs it on the examples by
  `native_decide`.
- `LCheck/` — the Lean-native checker `lcheck`, its data types and the pure
  functions the Go proof's specifications are stated over. Imports nothing
  beyond Lean's core (not even `Perennial.Std`: Lake would then compile all of
  Perennial and Iris) and is precompiled to native code (`lakefile.toml`).

## Building

    export PATH=$HOME/.elan/bin:$PATH
    lake build                                   # the whole library (Checkers.lean)
    lake env lean Checkers/Checker/Defs.lean     # one file
    go build ./... && go test ./...
    bash gocheck/demo.sh                         # checker demo + Lean timings
    bash gocheck/observe.sh; bash gocheck/tcheck/observe.sh   # recheck the observations
    bash gocheck/native.sh; bash gocheck/native_bench.sh      # Lean-native checker inputs, timings

Go uses goose from the Lake dependency (`go.mod` replaces
`github.com/mit-pdos/perennial` with `.lake/packages/perennial`), so run
`lake build` (or anything that fetches the dependencies) before `go build`.
