# notes/ — persistent project memory

Plain markdown, committed. It exists so that a fresh agent or person, with no
conversation history, can pick up the work.

- **[STATUS.md](STATUS.md)** — where things are. **Start here.**
- **[decisions.md](decisions.md)** — why the branch is the way it is. Newest last.
- **[porting.md](porting.md)** — Rocq file → Lean file, conventions, build commands.
- **[checker-port.md](checker-port.md)** — how a Rocq per-function proof of the
  checker maps to Lean, and the gotchas the port hit.
- **[journal.md](journal.md)** — dated log. Append-only, newest last.

Conventions as on `main` (`git show main:notes/README.md`): write for a
stranger, absolute dates, record dead ends, correct rather than append
(except the journal).
